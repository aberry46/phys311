This week, the physics itself was familiar as we were building on the same forces, collisions, and conservation laws that we already implemented using Python. The equations and logic translated fairly naturally to JavaScript, which was at the very least a helpful pathway to begin the full rollover. What did feel alien however was adapting everything into a browser environment. As I mentioned in this week's discussion, managing animation frames and maintaining a consistent timestep was certainly difficult. Unlike Python, we were unable to control simulation loop directly. JavaScript introduced a separate layer of complexity in its updating and display issues. 

What I found to be interesting this week was realizing that the physics itself did not need to change but more in the way that I implemented it. Similar to the translation of writing down equations vs. coding them into Python, rolling over Python methods into JavaScript required me to understand WHY numerical stability matters beyond simply writing down / vibe coding an equation. I certainly have experienced this before, but I feel like having this half-way transition into a different coding language has proved extremely helpful for my learning!

Overall, this week was certainly difficult, but I think what we are doing is extremely rewarding.
