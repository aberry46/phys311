# PHYS 311: Lab 9 - Multi-Body Simulation

A modular JavaScript physics engine supporting multiple
bodies, forces, collisions, and numerical integration.

## Live Simulation
[Launch Lab 9](https://aberry46.github.io/phys311/labs/lab09/)

## Scenes
- **Billiards:** Elastic and inelastic collisions with adjustable restitution.
- **N-Body Gravity:** Five-body gravitational simulation with orbital trails.
- **Spring Network:** Coupled spring-mass oscillations.
- **Jitter Test:** Demonstrates the separating-velocity collision guard.

## Controls
- Select simulation scene and numerical integrator.
- Adjust ball count and restitution.
- Enable or disable the jitter guard.
- Pause, resume, or reset the simulation.
- Log conservation and performance measurements to the Console.

## Running Locally
Open `index.html` using VS Code Live Server.
